# x-layer_performance_evaluation_of_PQ_X.509
Supplementary data and code for the paper “A Cross-Layer Performance Evaluation of Post-Quantum X.509 Authentication over Wi-Fi.” Includes per-exchange results for 551 ns-3 runs (439,830 completed exchanges), DER-encoded certificate/signature sizes, and the ns-3.48/OpenSSL 3.5.7 integration code.
